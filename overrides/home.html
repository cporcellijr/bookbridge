Why not Whispersync?

Whispersync, for the books you already own.

Amazon's Whispersync for Voice switches between a Kindle book and its Audible audiobook, when you bought both from Amazon and the editions match. BookBridge does the same job for your own files.

  • {% include ".icons/material/check.svg" %}Your files, any store. Audiobooks and EPUBs from anywhere; the alignment comes from the audio and text themselves.
  • {% include ".icons/material/check.svg" %}Your server. Runs in Docker at home. No Amazon account, no cloud service in between.
  • {% include ".icons/material/check.svg" %}Your readers. KOReader, Kobo, web readers and audiobook apps, side by side.

Install

Up and running in minutes.

  1. Add it to Docker Compose

    One container, one data folder, and your ebook folder.

  2. Start it and sign in

    Run docker compose up -d and open the dashboard on port 8080.

  3. Connect your apps

    Add each app in Settings, test the connection and link your first book.

Read the setup guide {% include ".icons/material/arrow-right.svg" %}
services:
  bookbridge:
    image: ghcr.io/cporcellijr/bookbridge:latest
    restart: unless-stopped
    ports:
      - "8080:5757"
    environment:
      - TZ=America/New_York
    volumes:
      - ./data:/data
      - /path/to/ebooks:/books
# Everything else is set up in the web UI.
