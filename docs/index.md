# BookBridge

Read it. Hear it. Never lose your place. BookBridge switches between the audiobook and the ebook of the same book, across the apps you already use. It is open source and self-hosted.

Start with [Getting Started](getting-started.md), see [How BookBridge works](how-it-works.md), or browse the [Configuration](configuration.md) reference.
