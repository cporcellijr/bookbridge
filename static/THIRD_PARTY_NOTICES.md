## New interface fonts

The New interface self-hosts Literata, Instrument Sans and IBM Plex Mono as WOFF2
files (`fonts/next-*.woff2`, mapped by `fonts/next-fonts.css`). Font subsets and
variable weight ranges were obtained from the Google Fonts CSS API on 2026-11-04;
no browser requests to Google Fonts are made. Each is distributed under the SIL
Open Font License 1.1, with the full copyright and OFL text included here:

| Family | Upstream source | Included license |
|---|---|---|
| Literata | https://github.com/google/fonts/tree/main/ofl/literata | `fonts/OFL-literata.txt` |
| Instrument Sans | https://github.com/google/fonts/tree/main/ofl/instrumentsans | `fonts/OFL-instrumentsans.txt` |
| IBM Plex Mono | https://github.com/google/fonts/tree/main/ofl/ibmplexmono | `fonts/OFL-ibmplexmono.txt` |

Where a licence is marked "not verified", the logo's terms of use were not
confirmed; contact the owner before redistributing it outside this project.
`calibre-web.png` was resized and cropped to its glyph for use as a small icon.
